# ImageLingo 0.6.1

이미지 폴더 전체를 Gemini, OpenAI 또는 Vertex AI로 순차 번역하고, 원문 위에 반투명 박스와 한국어 번역문을 합성한 PNG 파일로 저장하는 개인용 Android 앱입니다.


## 0.6.1 핫픽스

- 0.6 업데이트 ZIP에서 누락된 `TranslatedImageRenderer.java` 복구
- GitHub Actions의 `cannot find symbol TranslatedImageRenderer` 컴파일 오류 수정
- 앱 버전 0.6.1로 상향

## 0.6 업데이트

- 상단에 **실시간 번역 진행 현황** 추가
  - 예: `번역 완료 37 / 100 · 37% · 처리 38페이지`
- 앱을 다시 실행해도 `ImageLingo_Translated` 폴더를 스캔해 완료 페이지 수를 복원
- 상단 오른쪽에 **번역본만** 보기 버튼 추가
- 번역본만 보기 모드에서는 저장된 번역 이미지가 있는 페이지만 필터링
- 번역본 모드 상태를 저장해 다음 실행에서도 유지
- 폴더 번역 중에는 보기 모드 전환을 잠시 비활성화
- 기존 번역 중지, 이미 번역된 파일 건너뛰기, 누적 토큰 표시 유지

## 주요 기능

- 이미지 폴더 선택
- 숫자가 포함된 파일명 자연 정렬 (`1, 2, 10`)
- 좌우 스와이프 및 이전/다음 버튼
- 핀치 확대, 드래그, 두 번 탭 확대
- 폴더 전체 순차 번역
- 번역 결과를 이미지 자체에 합성하여 PNG로 저장
- 번역된 파일 자동 건너뛰기
- 번역 중지 버튼
- 번역된 파일만 보기 모드
- 상단 실시간 완료 페이지 및 퍼센트 표시
- 시스템 프롬프트 입력
- 실제 API 토큰 사용량 표시
- Gemini API, OpenAI Responses API, Vertex AI 지원

## 실시간 상단 표시

평상시에는 다음과 같이 전체 번역 현황을 표시합니다.

```text
번역 완료 37 / 100 · 37%
```

폴더 번역 중에는 현재 처리 중인 원본 페이지 번호도 함께 표시합니다.

```text
번역 완료 37 / 100 · 37% · 처리 38페이지
```

`번역본만` 모드에서는 끝에 `번역본 모드`가 추가됩니다.

## 번역된 파일만 보기

상단 오른쪽의 **번역본만** 버튼을 누르면 `ImageLingo_Translated` 폴더에 결과 파일이 있는 페이지만 보여줍니다.

- 번역본 모드에서 버튼은 **전체 보기**로 바뀝니다.
- 번역본이 하나도 없으면 안내 화면이 표시됩니다.
- 앱 재실행 후에도 출력 폴더를 다시 스캔하므로 기존 번역본이 자동으로 나타납니다.

## 저장 방식

번역 결과는 선택한 원본 폴더 안의 다음 폴더에 저장됩니다.

```text
ImageLingo_Translated
```

파일명 예시:

```text
page01_translated.png
```

원본 이미지는 변경하지 않습니다. 같은 출력 파일이 이미 있으면 API를 다시 호출하지 않고 건너뜁니다.

## 번역 중지

번역 도중 왼쪽 아래 **번역 중지** 버튼을 누르면 현재 API 요청과 이미지 저장을 마친 뒤 안전하게 중단합니다.

## 기존 프로젝트 업데이트

업데이트 ZIP을 기존 `ImageLingo` 폴더에 덮어쓴 뒤 Termux에서 실행합니다.

```bash
cd /storage/emulated/0/Download/ImageLingo
unzip -o ../ImageLingo-v0.6-update.zip
git add .
git commit -m "Update ImageLingo to 0.6"
git push
```

GitHub Actions 빌드가 완료되면 실행 요약 화면의 **Artifacts → ImageLingo-debug-apk**에서 APK를 받을 수 있습니다.

## 현재 한계

- 실제 배경 복원형 인페인팅이 아니라 반투명 박스와 번역문을 이미지에 합성하는 방식입니다.
- 세로쓰기, 곡선 효과음, 매우 작은 글자는 모델이 좌표를 조금 잘못 잡을 수 있습니다.
- 선택한 폴더 바로 아래의 이미지만 처리하며 하위 폴더는 재귀 탐색하지 않습니다.
- 출력 형식은 PNG입니다.
- 민감한 이미지는 외부 API로 전송하지 않는 것이 좋습니다.
