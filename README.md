# ImageLingo 0.9

이미지 폴더 전체를 Gemini, OpenAI 또는 Vertex AI로 순차 번역하고, 원문 위에 반투명 박스와 한국어 번역문을 합성한 PNG 파일로 저장하는 개인용 Android 앱입니다.

## 0.9 업데이트

### 429 자동 대응

- HTTP 429 발생 시 `5초 → 10초 → 20초 → 40초 → 60초` 순서로 자동 재시도
- API가 `Retry-After` 또는 Google의 `retryDelay`를 반환하면 더 긴 서버 권장 대기 시간을 우선 적용
- 우측 하단 배지에 남은 대기 시간과 재시도 횟수 표시
- 자동 재시도를 모두 사용해도 429가 계속되면 해당 페이지에서 **일시정지**
- 중앙 버튼이 **계속하기**로 바뀌며, 한도·결제·모델 설정을 확인한 뒤 같은 페이지부터 다시 시도
- 자동 대기 또는 일시정지 중에도 **번역 중지** 가능

### 속도 개선

- 누적 줄거리 요약과 페이지 요약 기능 완전 제거
- 문맥은 이름·고유명사·높임체·호칭과 **직전 1페이지의 짧은 번역문**만 전송
- API 전송 이미지 최대 변을 2048px에서 1600px로 축소
- JPEG 품질을 82로 최적화
- 최대 출력 토큰을 5000에서 2500으로 축소
- OpenAI 이미지 세부 설정을 `auto`로 변경
- Gemini·Vertex 출력 온도를 0.1로 낮춤

### 번역 박스 가독성

- 흰색 박스를 기존보다 훨씬 불투명하게 변경
- 테두리와 그림자를 강화
- 모든 흰색 박스를 먼저 그리고 번역문을 나중에 그리는 2단계 렌더링 적용
- 번역 박스가 겹쳐도 뒤에서 그려진 박스가 앞 번역문을 흰색으로 덮는 현상 완화

## 문맥 유지 기능

폴더별 문맥은 번역 결과 폴더 안의 다음 파일에 저장됩니다.

```text
ImageLingo_Translated/translation_memory.json
```

유지되는 정보:

- 등장인물 원문 이름과 통일된 한국어 이름
- 인물별 말투와 존댓말·반말 규칙
- 인물 간 호칭
- 작품 고유명사와 통일 번역
- 직전 1페이지의 짧은 번역 문맥

0.8에서 저장된 `story_summary`, 페이지별 `summary` 값은 0.9에서 문맥 파일을 읽을 때 자동으로 제거됩니다.

## 기존 기능

- 폴더 번역 중 좌우 스와이프, 이전·다음, 확대·이동
- 번역 중 `번역본만` / `전체 보기` 전환
- 완료된 페이지와 현재 처리 중인 페이지를 번역본 모드에 실시간 추가
- 폴더 전체 순차 번역
- 원문 위 번역 박스와 글자를 이미지에 직접 합성
- 번역 결과 PNG 저장
- 이미 번역된 파일 자동 건너뛰기
- 번역 중지 버튼
- 상단 완료 페이지·퍼센트·현재 처리 페이지 표시
- 시스템 프롬프트 입력
- 실제 API 토큰 사용량 표시
- Gemini API, OpenAI Responses API, Vertex AI 지원

## 429 일시정지 사용법

자동 재시도 이후에도 제한이 계속되면:

1. 앱은 현재 페이지에서 일시정지합니다.
2. OpenAI/Gemini/Vertex의 사용량 한도, 결제 상태 또는 모델 설정을 확인합니다.
3. 앱 중앙의 **계속하기**를 누릅니다.
4. 실패했던 같은 페이지부터 다시 요청합니다.
5. 작업을 끝내려면 왼쪽 아래 **번역 중지**를 누릅니다.

무료 일일 한도나 결제 한도가 소진된 경우에는 기다리거나 계정 한도를 조정해야 하며, 앱이 해당 제한 자체를 우회할 수는 없습니다.

## 저장 위치

```text
선택한 원본 폴더/ImageLingo_Translated/
```

출력 파일 예시:

```text
page01_translated.png
```

원본 파일은 수정하지 않으며 같은 출력 파일이 이미 있으면 API 요청 없이 건너뜁니다.

## 기존 프로젝트 업데이트

```bash
cd ~/ImageLingo-repair
unzip -o /storage/emulated/0/Download/ImageLingo-v0.9-update.zip
git add -A
git commit -m "Update ImageLingo to 0.9"
git push
```

GitHub Actions 빌드가 완료되면 실행 요약의 **Artifacts → ImageLingo-debug-apk**에서 APK를 받을 수 있습니다.

## 현재 한계

- 실제 배경 복원형 인페인팅이 아니라 번역 박스와 번역문을 이미지에 합성하는 방식입니다.
- 이미지 축소로 속도는 빨라졌지만, 매우 작거나 흐릿한 글자는 인식률이 낮아질 수 있습니다.
- 계정의 일일 한도·크레딧 소진·프로젝트 할당량 부족은 앱 재시도만으로 해결되지 않습니다.
- 선택한 폴더 바로 아래의 이미지만 처리하며 하위 폴더는 재귀 탐색하지 않습니다.
- 출력 형식은 PNG입니다.
