# ImageLingo 0.7

이미지 폴더 전체를 Gemini, OpenAI 또는 Vertex AI로 순차 번역하고, 원문 위에 반투명 박스와 한국어 번역문을 합성한 PNG 파일로 저장하는 개인용 Android 앱입니다.

## 0.7 업데이트

- **폴더 번역 중에도 페이지 이동 가능**
  - 좌우 스와이프
  - 이전·다음 버튼
  - 확대·이동
- 번역 작업과 사용자가 보고 있는 페이지를 분리
  - 백그라운드 번역이 다음 파일로 넘어가도 보고 있던 페이지를 강제로 바꾸지 않음
- **번역 중에도 `번역본만` / `전체 보기` 전환 가능**
- `번역본만` 모드에 다음 페이지가 실시간으로 추가됨
  - 이미 번역 완료된 페이지
  - 현재 API가 처리 중인 페이지
  - 방금 저장된 새 번역 페이지
- 번역본 목록은 원본 파일 순서를 유지
- 번역본 모드에서 마지막 페이지를 보고 있으면 새 처리 페이지를 자동으로 따라감
- 사용자가 이전 페이지로 돌아가 읽기 시작하면 최신 페이지로 강제로 끌고 가지 않음
- 현재 보고 있는 처리 페이지는 `번역 중`, 저장 완료된 페이지는 `저장됨`으로 표시
- 상단 진행 문구 개선

```text
번역 완료 37 / 100 · 37% · 현재 38 / 100페이지 · 번역본 모드
```

## 주요 기능

- 이미지 폴더 선택
- 숫자가 포함된 파일명 자연 정렬 (`1, 2, 10`)
- 좌우 스와이프 및 이전·다음 버튼
- 핀치 확대, 드래그, 두 번 탭 확대
- 폴더 전체 순차 번역
- 번역 결과를 이미지 자체에 합성하여 PNG로 저장
- 번역된 파일 자동 건너뛰기
- 번역 중지 버튼
- 번역된 파일만 보기 모드
- 번역 중 실시간 번역본 목록 갱신
- 상단 실시간 완료 페이지·퍼센트·현재 처리 페이지 표시
- 시스템 프롬프트 입력
- 실제 API 토큰 사용량 표시
- Gemini API, OpenAI Responses API, Vertex AI 지원

## 번역 중 페이지 읽기

폴더 번역을 시작한 뒤에도 화면을 자유롭게 넘길 수 있습니다. 번역기는 별도 작업으로 계속 진행되며 사용자가 보는 페이지를 바꾸지 않습니다.

`번역본만` 모드에서는 완료된 번역본과 현재 처리 중인 페이지가 원본 순서대로 표시됩니다. 최신 페이지를 보고 있을 때는 새 처리 페이지를 자동으로 따라가며, 이전 페이지로 이동하면 자동 따라가기가 멈춥니다.

## 저장 방식

번역 결과는 선택한 원본 폴더 안의 다음 폴더에 저장됩니다.

```text
ImageLingo_Translated
```

파일명 예시:

```text
page01_translated.png
```

원본 이미지는 변경하지 않습니다. 같은 출력 파일이 이미 있으면 API를 다시 호출하지 않고 건너뜁니다.

## 번역 중지

번역 도중 왼쪽 아래 **번역 중지** 버튼을 누르면 현재 API 요청과 이미지 저장을 마친 뒤 안전하게 중단합니다.

## 기존 프로젝트 업데이트

Termux 내부의 정상 Git 저장소에서 실행합니다.

```bash
cd ~/ImageLingo-repair
unzip -o /storage/emulated/0/Download/ImageLingo-v0.7-update.zip
git add -A
git commit -m "Update ImageLingo to 0.7"
git push
```

GitHub Actions 빌드가 완료되면 실행 요약 화면의 **Artifacts → ImageLingo-debug-apk**에서 APK를 받을 수 있습니다.

## 현재 한계

- 실제 배경 복원형 인페인팅이 아니라 반투명 박스와 번역문을 이미지에 합성하는 방식입니다.
- 현재 처리 중인 페이지는 번역 저장 전까지 원본 이미지로 보이고, 저장 완료 즉시 합성된 번역 이미지로 갱신됩니다.
- 세로쓰기, 곡선 효과음, 매우 작은 글자는 모델이 좌표를 조금 잘못 잡을 수 있습니다.
- 선택한 폴더 바로 아래의 이미지만 처리하며 하위 폴더는 재귀 탐색하지 않습니다.
- 출력 형식은 PNG입니다.
