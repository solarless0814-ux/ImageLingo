# ImageLingo 0.8

이미지 폴더 전체를 Gemini, OpenAI 또는 Vertex AI로 순차 번역하고, 원문 위에 반투명 박스와 한국어 번역문을 합성한 PNG 파일로 저장하는 개인용 Android 앱입니다.

## 0.8 업데이트: 문맥 유지 번역

각 페이지를 독립적으로 번역하지 않고, 같은 폴더의 이전 번역 문맥을 다음 API 요청에 자동 첨부합니다.

자동으로 유지하는 정보:

- 등장인물 원문 이름과 통일된 한국어 이름
- 인물별 말투, 존댓말·반말 관계
- 인물 간 호칭
- 작품 고유명사와 번역 표기
- 현재 페이지까지의 짧은 누적 줄거리
- 최근 3페이지의 요약과 번역문

모델 응답에서 새 인물·용어·호칭을 발견하면 문맥 메모리에 합치고, 다음 페이지부터 바로 적용합니다.

## 문맥 파일

폴더별 문맥은 번역 결과 폴더 안에 저장됩니다.

```text
ImageLingo_Translated/translation_memory.json
```

앱을 종료하거나 API 제공자를 바꿔도 파일이 남아 있으므로 다음 번역에서 다시 불러옵니다.

설정 화면의 **문맥 메모리** 항목에서:

- 현재 줄거리·인물·용어·호칭 JSON 확인
- 잘못된 이름이나 호칭 직접 수정
- 현재 폴더 문맥 초기화

가 가능합니다.

상단 진행 표시에는 저장된 문맥 항목 수도 함께 표시됩니다.

```text
번역 완료 37 / 100 · 37% · 현재 38 / 100페이지 · 문맥 14
```

## 이전 버전에서 유지되는 기능

- 폴더 번역 중에도 좌우 스와이프, 이전·다음, 확대·이동 가능
- 번역 중에도 `번역본만` / `전체 보기` 전환 가능
- 완료된 페이지와 현재 처리 중인 페이지가 번역본 모드에 실시간 추가
- 폴더 전체 순차 번역
- 원문 위 반투명 박스와 번역문을 이미지에 직접 합성
- 번역 결과 PNG 저장
- 이미 번역된 파일 자동 건너뛰기
- 번역 중지 버튼
- 상단 완료 페이지·퍼센트·현재 처리 페이지 표시
- 시스템 프롬프트 입력
- 실제 API 토큰 사용량 표시
- Gemini API, OpenAI Responses API, Vertex AI 지원

## 문맥 동작 방식

페이지를 번역할 때 API에는 다음 정보가 함께 전달됩니다.

1. 사용자가 입력한 시스템 프롬프트
2. 누적 줄거리 요약
3. 등장인물 이름·말투 사전
4. 고유명사 사전
5. 인물 간 호칭 사전
6. 최근 3페이지의 번역 문맥
7. 현재 페이지 이미지

API는 번역 블록과 함께 `page_summary`, `memory_updates`를 JSON으로 반환합니다. 앱은 결과를 `translation_memory.json`에 저장한 뒤 다음 페이지에 사용합니다.

## 기존 번역본 관련 주의

0.7 이하에서 이미 생성한 PNG 파일은 계속 자동으로 건너뜁니다. 다만 구버전 PNG에는 이름·말투 문맥 정보가 저장되어 있지 않으므로, 기존 `translation_memory.json`이 없는 폴더에서는 **0.8로 새로 번역한 첫 페이지부터** 문맥이 축적됩니다.

처음부터 완전한 문맥 통일이 필요하면 기존 `ImageLingo_Translated` 폴더의 번역 PNG를 별도로 백업하거나 삭제한 뒤 다시 번역하세요.

## 저장 방식

번역 결과는 선택한 원본 폴더 안의 다음 폴더에 저장됩니다.

```text
ImageLingo_Translated
```

파일명 예시:

```text
page01_translated.png
```

원본 이미지는 변경하지 않습니다. 같은 출력 파일이 이미 있으면 API를 다시 호출하지 않고 건너뜁니다.

## 기존 프로젝트 업데이트

Termux 내부의 정상 Git 저장소에서 실행합니다.

```bash
cd ~/ImageLingo-repair
unzip -o /storage/emulated/0/Download/ImageLingo-v0.8-update.zip
git add -A
git commit -m "Update ImageLingo to 0.8"
git push
```

GitHub Actions 빌드가 완료되면 실행 요약 화면의 **Artifacts → ImageLingo-debug-apk**에서 APK를 받을 수 있습니다.

## 현재 한계

- 실제 배경 복원형 인페인팅이 아니라 반투명 박스와 번역문을 이미지에 합성하는 방식입니다.
- AI가 인물 관계를 잘못 추정할 수 있으므로 중요한 이름·호칭은 설정의 문맥 편집 화면에서 확인하는 것이 좋습니다.
- 세로쓰기, 곡선 효과음, 매우 작은 글자는 모델이 좌표를 조금 잘못 잡을 수 있습니다.
- 선택한 폴더 바로 아래의 이미지만 처리하며 하위 폴더는 재귀 탐색하지 않습니다.
- 출력 형식은 PNG입니다.
